# Personal Webpage – Mohamed Alie Kamara

##  Project Overview

This project is a simple personal webpage built using basic HTML. It introduces Mohamed Alie Kamara, a Software Engineering student, and highlights his background, interests, academic journey, and career aspirations.

The webpage is designed as a beginner-friendly project to demonstrate foundational web development skills, including structuring content with HTML and organizing information clearly for users.


##  About the Author

* **Program:** Software Engineering with Multimedia
* **Institution:** Limkokwing University of Creative Technology

##  Features

* Personal introduction and background information
* Academic program details
* "About Me" section describing personal interests and character
* Explanation of why web design is being studied
* Detailed career goals (technology, football, and business)
* Contact information with email link
* Clean and simple layout using semantic HTML


##  Technologies Used

* **HTML5** (for structuring the webpage)

##  How to Run the Project

1. Download or clone the project files.
2. Open the `index.html` file in any web browser (Chrome, Edge, Firefox, etc.).
3. The webpage will load locally and display the content.
